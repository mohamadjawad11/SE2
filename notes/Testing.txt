🧠 What is Unit Testing?

Unit testing means:

Testing small, isolated pieces of code (units) to make sure they behave correctly.

A “unit” is usually:

A function
A class method
A small module


🎯 Goal of Unit Testing
Catch bugs early
Make code safer to change
Document expected behavior
Increase confidence when refactoring




refactoring
🔥 What should you test?

Test things that contain logic:

✔️ Validation (e.g. PriceValidator)
✔️ Business rules (e.g. “max price < 100”)
✔️ Calculations (e.g. revenue)
✔️ Conditions (if/else behavior)
✔️ Edge cases (empty arrays, invalid input)





🎯 What mocking does

👉 Replaces real dependencies with fake ones

Used for:

APIs
Databases
External services
Complex classes


A spy(proxy wrapper) lets you:

Watch how a function is used without replacing it completely

Use a spy only when you care about interaction between components

example => orderManagement.getTotalRevenue() => OrderManagement → uses FinanceCalculator
